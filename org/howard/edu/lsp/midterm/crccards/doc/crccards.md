# CRC collaboration

Library collaborates with Book because its CRC responsibilities include finding books and coordinating borrowing and returning, which require Book’s information and methods. Book’s responsibilities are to store its own information, maintain availability, and validate borrowing and returning, so it does not need to know about Library. Library enforces the three-book borrowing limit because it manages the entire collection and can count borrowed books, while each Book only knows its own availability. This keeps collection-wide rules in Library and individual book behavior in Book.
